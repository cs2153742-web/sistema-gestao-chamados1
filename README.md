\# Sistema de Gestão de Chamados



\## Descrição

Sistema para registrar e acompanhar chamados

de suporte técnico.



\## Objetivo

Facilitar o atendimento de solicitações

relacionadas à tecnologia.



\## Funcionalidades

\- Registrar chamados.

\- Identificar solicitantes.

\- Descrever problemas.

\- Acompanhar status.
